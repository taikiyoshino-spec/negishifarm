# 根岸FARM ホームページ

青森県のブルーベリー農園「根岸FARM」の公式サイトです。  
HTML・CSS・JavaScript のみで構成され、スマホ優先のレスポンシブデザインです。

開発時のブランチ運用ルールは [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

## 構成

- **index.html** … メインのHTML（商品一覧・連絡先・アクセス・新着情報・ギャラリー）
- **styles.css** … モバイルファーストのスタイル
- **script.js** … メニュー開閉・スムーススクロール・ギャラリーライトボックス

## カスタマイズ方法

### 連絡先（index.html の `#contact` 付近）

- **お名前** … `根岸 〇〇（ねぎし 〇〇）` を実際の名前に変更
- **電話番号** … `000-0000-0000` を実際の番号に変更（`<a href="tel:...">` も合わせて変更）
- **メール** … `info@example.com` を実際のアドレスに変更

### アクセス

- 地図の座標は指定の Google マップ URL（40.392525, 141.4846402）で設定済みです。
- 住所表記（〒031-xxxx 青森県八戸市付近）は実際の住所に合わせて変更してください。

### Googleカレンダー

- **予定の表示**: 現在は日本の祝日カレンダーをサンプル表示しています。
- **ご自身のカレンダーに差し替え**: [Googleカレンダー](https://calendar.google.com) → 設定（歯車）→ 左メニューで対象のカレンダーを選択 → 「カレンダーの統合」→ 「埋め込みコード」をコピー → `index.html` の `calendar-iframe` の `src` を差し替えてください。
- **注意**: カレンダーを「一般公開」に設定する必要があります。
- **開園状況・予約フォームの判定ルール**: トップページの「本日の開園状況」バッジと、予約フォームの日付選択は、いずれもこのカレンダーの予定で判定します。
  - 予定のタイトルに「休園」「臨時休業」「定休」「お休み」を含む → 休園・予約不可
  - 予定のタイトルに「オフシーズン」を含む → 「ブルーベリー狩りシーズン外」表示・予約不可（下記シーズン期間の設定より優先されるので、シーズンを早めに終える年はこの予定を入れてください）
  - 予定のタイトルに「開園」を含む → 開園・予約可能（ただし下記の受付時間内のみ「ただいま開園中」と表示）
  - **その日に該当する予定が1件もない場合は、自動的に「休園」扱い（予約も不可）になります。** 更新忘れで実際は休園なのに開園表示のまま、という事故を防ぐための仕様です。そのため、**開園する日は必ず当日分のカレンダー予定（タイトルに「開園」を含むもの）を登録してください。**
  - カレンダーの「開園」予定は「今日は営業日である」という意味でしかなく、受付時間（6:00〜16:00、`script.js`の`dayOpen`/`dayClose`）は別途チェックされます。そのため、営業時間外（16:00以降など）は「開園」予定がある日でも「本日の受付は終了しました」と表示されます。
  - `status.json`の`manual`欄（管理者による強制表示）を設定した場合は、カレンダーの予定より優先され、受付時間に関係なくその表示が常に反映されます（悪天候による急な休園など、緊急の上書き用途を想定）。

### 予約フォーム（Google Apps Script連携）

サイト上の予約フォーム（`#contact` 内）から送信された内容は、`nesscamod@gmail.com` アカウントで動かす Google Apps Script（GAS）のウェブアプリに送られ、そこで (1) 予約者への確認メール送信、(2) スタッフへの通知メール送信、(3) スプレッドシートへの記録、を行います。静的サイトのJavaScriptだけではメール送信・スプレッドシート書き込みはできない（認証情報を安全に埋め込めない）ため、この構成にしています。

**セットアップ手順**

1. `nesscamod@gmail.com` でログインし、Googleドライブで新規スプレッドシートを作成する
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く
3. エディタの中身をすべて削除し、[gas/Code.gs](gas/Code.gs) の内容をそのまま貼り付けて保存する
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類の選択で歯車アイコンから「ウェブアプリ」を選ぶ
5. 「次のユーザーとして実行」= **自分**、「アクセスできるユーザー」= **全員** に設定してデプロイ
   - 初回は権限の承認を求められるので、Googleアカウントの確認画面で許可する
6. 発行されたウェブアプリのURL（`https://script.google.com/macros/s/.../exec`）をコピーする
7. [script.js](script.js) 内の `NEGISHI_RESERVATION_CONFIG.webAppUrl` にそのURLを貼り付けてコミットする

```js
var NEGISHI_RESERVATION_CONFIG = {
  webAppUrl: 'https://script.google.com/macros/s/XXXXXXXX/exec'
};
```

**動作確認**

- サイトの予約フォームから1件テスト送信する
- スプレッドシートに行が追加されていること
- 入力したメールアドレスに確認メールが届くこと
- `nesscamod@gmail.com` にスタッフ通知メールが届くこと
- の3点を確認してください。

**注意**

- GASのコード（`gas/Code.gs`）を変更した場合は、Apps Scriptエディタ側にも同じ内容を貼り直し、「デプロイを管理」から**既存デプロイを更新**する必要があります（新しいデプロイを作るとURLが変わってしまいます）。
- Googleカレンダーで休園日として登録した日は、フォームの日付選択時に自動で「この日は休園予定です」と表示されます（[開園状況の設定](#googleカレンダー)と同じキーワード判定を利用）。

### 新着情報（Twitter / X）

- **リンク** … `id="twitterLink"` の `<a>` の `href` を公式 X（Twitter）のURLに変更
- **タイムライン埋め込み** … X の「タイムラインを埋め込む」で取得したコードを、`id="twitterEmbed"` の div 内に貼り付けてください。

### ギャラリー

- 現在は色のプレースホルダーです。実際の写真を使う場合は、各 `.gallery-thumb` の中に `<img src="画像URL" alt="説明">` を追加し、必要に応じて `data-full="大サイズ画像URL"` を付けるとライトボックスで拡大表示できます。

## ローカルで確認

`index.html` をブラウザで開くか、簡易サーバーで表示してください。

```bash
# 例: Python 3
python -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```
